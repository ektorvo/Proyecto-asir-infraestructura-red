# Proyecto-asir-infraestructura-red
Diseño e implantación de red multi-sede (AD, DNS, DHCP, VLANs, PostgreSQL, VPN simulada

Proyecto de fin de ciclo (ASIR) orientado a la implantación de una infraestructura para una empresa con:
- Active Directory (Windows Server)
- DNS / DHCP
- Segmentación por VLANs
- Control de acceso entre redes
- Servicios internos (ej. PostgreSQL)
- Simulación y documentación (Packet Tracer + capturas)

## Tecnologías
- Windows Server (AD DS, DNS, DHCP)
- Redes (VLANs, routing, ACLs)
- Virtualización / laboratorio
- Documentación y procedimientos

## Qué se incluye en este repositorio
- Documentación resumida del proyecto
- Diagramas de red
- Capturas de configuración
- Guías paso a paso (instalación / despliegue)

## Estado
Repositorio preparado como portfolio para entrevistas y prácticas FCT.
