# Proyecto ASIR – Infraestructura de Red Multi-Sede

Diseño e implantación de una infraestructura IT para una empresa con dos sedes (Valladolid y Burgos), simulando un entorno real corporativo.

## 🎯 Objetivo del proyecto

Diseñar y desplegar una red empresarial segura y segmentada que permita:

- Gestión centralizada de usuarios (Active Directory)
- Resolución de nombres y asignación dinámica de IP (DNS / DHCP)
- Segmentación por VLANs
- Control de acceso entre redes mediante ACLs
- Servicio interno de base de datos (PostgreSQL)
- Conectividad entre sedes mediante VPN simulada

---

## 🏗 Arquitectura

Infraestructura multi-sede compuesta por:

- Windows Server (AD DS, DNS, DHCP)
- Router con inter-VLAN routing
- Segmentación en VLAN:
  - Administración
  - Cocina
  - TPV
  - Clientes
- ACLs para restricción de tráfico
- Simulación completa en Cisco Packet Tracer

---

## 🛠 Tecnologías utilizadas

- Windows Server 2019
